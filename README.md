# automation-lab-6

Учебный проект к лабораторной работе № 6 «Автоматизация процессов внедрения и поддержки компьютерных систем».

## Состав

- `app.py` - простое приложение: расчёт стоимости заказа со скидкой
- `test_app.py` - модульные тесты (pytest)
- `requirements.txt` - зависимости проекта
- `.github/workflows/main.yml` - CI-пайплайн GitHub Actions

## Запуск

```
pip install -r requirements.txt
pytest -v
```

При каждом push в ветку `main` GitHub Actions автоматически устанавливает зависимости, проверяет код линтером и запускает тесты.
